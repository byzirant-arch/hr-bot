# Бот для работников в MAX

Информационный бот по ТЗ: заработная плата, суточные, билеты, справки и документы.
Библиотека: `maxapi` (официальный Bot API Max), режим long polling.

## Переменные окружения (Bothost → «Переменные окружения»)
| Переменная | Значение |
|---|---|
| `MAX_BOT_TOKEN` | токен бота из business.max.ru (никому не показывать) |
| `ADMIN_IDS` | Max ID администраторов через запятую (по умолчанию 329632295) |
| `RESPONSIBLE_IDS` | Max ID ответственных, получают уведомления (по умолчанию 245949538) |
| `BOT_TZ` | часовой пояс, по умолчанию Europe/Moscow |
| `REMIND_BEFORE_HOURS` | за сколько часов до срока напоминать, по умолчанию 4 |

## Файлы
- `main.py` — запуск и логика бота (точка входа)
- `menu_config.py` — меню, вопросы, тексты, сроки ответов (здесь добавляются новые разделы)
- `validators.py` — проверка введённых данных
- `db.py` — база SQLite (`/app/data/bot.db`)
- `config.py` — настройки из переменных окружения
- `dashboard.py` + `index.html` — веб-дашборд (включается переменной `DASHBOARD_PASSWORD`)

## Как пользоваться
- Работник: нажимает «Начать» у бота и работает через кнопки.
- Администратор и ответственный: кнопка «🛠 Панель сотрудника» в главном меню или команда `/admin`.
  - Администратор: даты выплат + заявки.
  - Ответственный: заявки (смена статуса, ответ работнику).
- `/myid` — бот пришлёт ваш Max ID (нужен, чтобы добавить сотрудника в ADMIN_IDS / RESPONSIBLE_IDS).

Важно: ответственный и администратор должны один раз нажать «Начать» у бота,
иначе бот не сможет отправлять им уведомления.

## Дашборд (index.html)
Бот сам отдаёт страницу со статистикой и заявками из своей базы. Включается переменными:
| Переменная | Значение |
|---|---|
| `DASHBOARD_PASSWORD` | пароль, не короче 8 символов (без него дашборд выключен) |
| `DASHBOARD_USER` | логин, по умолчанию `admin` |
| `DASHBOARD_PORT` | порт, по умолчанию 8080 (или значение `PORT`) |

Доступ только по логину и паролю, после 5 неверных попыток адрес блокируется на 15 минут.
Из дашборда можно отвечать работникам и менять статус заявок: клик по заявке → «Ответить работнику» или кнопки статуса. Работник получает сообщение в Max от имени бота. Эти действия защищены от подделки запросов с чужих сайтов. Адрес `/health` отвечает «ok» без пароля.
Статистика есть и в самом боте: «Панель сотрудника» → «Статистика».
